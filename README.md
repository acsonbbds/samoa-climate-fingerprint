# Samoa: A Climate Fingerprint in Motion

Interactive data visualization created for the **Pacific Dataviz Challenge 2026**.

## Live visualization

https://acsonbbds.github.io/samoa-climate-fingerprint/

## Story

From 1993 to 2023, four climate signals in Samoa show a broad shift toward:

- warmer ocean temperatures
- warmer surface temperatures
- higher sea level
- greater rainfall variability

The visualization uses rolling 10-year windows to reveal how these signals evolve together through time.

## Data

Pacific Data Hub / Pacific Community (SPC)

Indicators used:

- Sea Surface Temperature anomalies
- Surface Temperature anomalies
- Precipitation anomalies
- Sea Level Anomalies
